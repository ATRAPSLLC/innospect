# The compiler matrix: every Inno Setup the fixtures are built with.
#
#   <slug>  <installer URL>  <scripts>
#
# `<slug>` names the fixtures (`plain-tool<slug>.exe`) and the install
# directory in the image (`C:\inno\<slug>`). `<scripts>` is what
# `build-wine.sh --all` compiles with it, comma-separated; `alt` builds
# every other script a second time into `-alt` names, the nondeterminism
# check.
#
# Each URL is the exact installer the committed fixture's version marker
# calls for: 5.3.11, 5.4.3 and 5.5.5 are Unicode builds (`(u)`), 5.0.8,
# 5.1.14, 5.2.3 and 5.5.7 ANSI, `6_0_0u` the 6.0.0 beta, and `7_0_0_1`
# (marker 7.0.0.1) the 7.0.0 preview-3. `full.iss` is built with 6.1.0
# and 6.4.0, the two header formats the third-party installers it replaces
# were built with, with 6.4.2 (the first `(6.4.2)` header), and with 7.0.2
# and 7.1.1. 7.0.2 writes marker 7.0.0.3, the format 7.0.0 through 7.1.0
# share; 7.1.1 writes 7.1.1. Both are the 32-bit compiler editions, which
# build 64-bit installers too (`-x64`). `password` is built once per place
# the password verifier has lived: the pre-6.4 header (5.5.7), the 6.4
# header tail (6.4.3) and the 6.5+ encryption header (7.0.2, 7.1.1).
#
# `legacy.iss` is built once per setup data marker from 1.3.25 to 4.2.6,
# each with the last release that writes it (a beta or pre-release where
# only one did: 3.0.0, 3.0.2, 3.0.3, 3.0.4, 4.0.0, 4.0.2, 4.0.4). 3.0.4
# and 4.2.4 are there for their layouts: they write the markers 3.0.3 and
# 4.2.3, the formats 3.0.3 and 4.2.3 also write. No 1.2.x row: the one
# 1.2 package left is the 16-bit edition, which Wine cannot run.
#
# `plain.iss` is also built once per remaining 5.x and 6.x marker, with the
# last release that writes it, and from 5.3.0 to 5.5.x in both editions: a
# slug ending `u` is the Unicode build, and `5_3_11a`, `5_4_3a`, `5_5_5a` the
# ANSI builds beside the Unicode `5_3_11`, `5_4_3`, `5_5_5`. 5.5.8 and 5.6.1
# write 5.5.7's marker, 5.6.1 with the counted wizard-image lists.
#
# `-zip`, `-bzip`, `-lzma` and `-none` builds (`build-wine.sh`) cover every
# place the compression method shows: the per-file bzip2 flag (2.0.19), the
# bzip2 header option and its DLL before 4.1.5 (4.0.8, 4.1.4), 4.1.5's DLL
# for LZMA too, the zip DLL from 4.2.6 (4.2.7, 5.5.7, 7.1.1), and stored
# chunks (7.1.1). `modern.iss` (6.6.1, 6.7.0, 7.1.1) carries dark-mode and
# back wizard images and the 7-Zip DLL.
#
# `spanning.iss` (4.0+) and `spanning-legacy.iss` (1.x, 2.x) spread the
# payload over slice files, built once per slice-file generation: the
# `<base>.<n>` names before 2.0, `<base>-<n>.bin` with the header's base
# name to 4.x, the installer's own name from 5.0, `idska32` with a 32-bit
# size to 6.5.1 and `idskb32` with a 64-bit one from 6.5.2.
#
# `7_0_0p2` is 7.0.0 preview 2 and `7_0_0_1` preview 3: both write SetupID
# 7.0.0.1, and only preview 3 has the PBKDF2 bug its `password` build pins.
