#
#   <slug>  <installer URL>  <scripts>
#
# `<slug>` names the fixtures (`plain-tool<slug>.exe`) and the install
# directory in the image (`C:\inno\<slug>`). `<scripts>` is what
# `build-wine.sh --all` compiles with it, comma-separated; `alt` builds
# every other script a second time into `-alt` names, the nondeterminism
# check.
#

# calls for: 5.3.11, 5.4.3 and 5.5.5 are Unicode builds (`(u)`), 5.0.8,

# (marker 7.0.0.1) the 7.0.0 preview-3. `full.iss` is built with 6.1.0
# and 6.4.0, the two header formats the third-party installers it replaces
# were built with.
